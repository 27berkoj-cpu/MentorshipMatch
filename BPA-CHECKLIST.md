# BPA Project Checklist

This checklist converts the event requirements into project tasks. Mark each item complete only after it has been implemented and tested.

## Required application features

- [ ] User registration with validation.
- [ ] Login, logout, password hashing, and protected pages.
- [ ] Student profile management.
- [ ] Mentor profile management.
- [ ] Mentor search and filtering.
- [ ] Student mentor requests.
- [ ] Mentor accept and decline actions.
- [ ] Mentor availability management.
- [ ] Session booking and cancellation.
- [ ] Student and mentor messaging.
- [ ] Reviews after completed sessions.
- [ ] Admin user management with add, edit, and delete safeguards.
- [ ] Admin reports based on live database queries.
- [ ] Flagged activity review and action tracking.

## Technical scoring checklist

- [ ] PostgreSQL database is used; no flat-file data storage.
- [ ] Schema has primary keys, foreign keys, unique constraints, and useful indexes.
- [ ] Database relationships are documented in a conceptual model.
- [ ] Sensitive data is protected with password hashing and HTTPS in deployment.
- [ ] Access is controlled by authentication and role-based authorization.
- [ ] SQL queries are parameterized.
- [ ] Client-side and server-side validation are both present.
- [ ] Server errors are handled consistently.
- [ ] Session state works across page requests.
- [ ] Reports accurately match database data.
- [ ] Admin actions are logged where appropriate.
- [ ] Search returns relevant results.
- [ ] Pages work on desktop and mobile browsers.
- [ ] Navigation links are tested from every page.
- [ ] Chapter, team members, theme, school, city, state, and year appear somewhere on the site.

## Presentation evidence to prepare

- [ ] System architecture diagram.
- [ ] Database conceptual model.
- [ ] Short explanation of the development process.
- [ ] Explanation of frontend, backend, and database responsibilities.
- [ ] Demonstration accounts for student, mentor, and admin roles.
- [ ] Test examples showing validation, authorization, and error handling.
- [ ] Development audit trail showing planning, implementation, testing, and revisions.

## Submission documents

- [ ] Combined PDF with clickable website URL.
- [ ] Written project description.
- [ ] Source code and database schema.
- [ ] Works Cited.
- [ ] BPA release forms.
- [ ] AI Usage and Documentation Form.
- [ ] Correct Team ID filename and submission before the deadline.
